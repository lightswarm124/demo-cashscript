# Contracts

This directory is the active home for new CashScript work.

## Layout

- Create one folder per use case.
- A use-case folder may contain multiple contracts, shared helpers, TypeScript interaction code, and tests.
- Use `shared/` for primitives that are reused across multiple use cases.

## Initial Use-Case Folders

- `cdp/`
- `dex/`
- `escrow/`
- `oracle/`
- `payments/`
- `shared/`

Add more folders as new protocol families are introduced.
